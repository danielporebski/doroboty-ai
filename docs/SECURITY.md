# Prototype data boundary

This static frontend has no trusted server or real authentication. Role-specific UI and local transition checks organize the scenario; anyone using the browser can inspect all stored data. Use synthetic scenario data. In optional E01, a participant may record only their own voice; never record another person or include identifying or confidential details in audio or transcripts. Participants must understand that anyone with access to the same browser can read local recordings and scenario data.

No API keys, credentials, real CVs, identifying details or confidential material belong in frontend source, JSON, localStorage or exports. A participant's E01 voice recording and transcript are the documented exception: they are stored in this browser's localStorage and included in full-scenario JSON exports, which must be treated as private files. Personal audio expires after seven days from its recordedAt timestamp; the entire containing pre-interview (answers, transcripts and derived report) is removed on startup, import/export, every minute while open and on window focus. Closed browsers clean up on the next launch. Undated legacy audio and future timestamps expire immediately. Exports cannot extend the clock and must be deleted separately after the exercise. Participants use their own device or a separate browser profile. Reset replaces participant changes with baseline fixtures; clearing this site's browser data removes its local copy. Downloaded exports and recovery files must be deleted separately. Exports also include source/recruiter notes that are private only in the UI.

Render imported text through React text nodes, validate imports with shared Zod schemas, reject unsupported versions, duplicate IDs, broken references and oversized files. Never overwrite an unreadable save automatically.
